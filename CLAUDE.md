# North Huddle

Unofficial Minnesota football fan hub (owner: TheOldMan21). Hosted on Cloudflare Pages from this repo's `main` branch; every push redeploys in about a minute.

## Layout
- `src/hub.html` — the app (markup, CSS, all feature scripts). Edit this for features/UI.
- `src/shim.js` — data layer: implements the `claude.use("db"|"user")` API the app was written against, on top of Supabase (`docs` table: path → JSON).
- `src/site.js` / `src/site.css` — North Huddle overrides: email sign-in sheet, branding + disclaimer footer, update requests, live scores polling `/api/scores`.
- `build.py` — assembles `index.html` from the above. **Always run `python3 build.py` after editing anything in `src/`, and commit `index.html`.**
- `functions/api/scores.js` — Cloudflare Pages Function proxying ESPN's scoreboard + scoring plays (30 s edge cache).
- `js/supabase.js` — vendored supabase-js 2.45.4 UMD.
- `supabase/admin.sql` — admin page support (banned table, admin_users RPC, can_write with ban check). Run AFTER setup.sql whenever setup.sql is re-run.
- `src/round3.js` — spam filter (no links/repeats), pick'em, fan power rankings, member profiles, AI recaps (`functions/api/recap.js`), watch party (game view only). Fan chat and game chat were removed from the UI in Nov 2026 (code paths left inert; chat/gamechat collections unused).
- `src/stadium.js` — Depth "Stadium" view: starters on img/field/stadium.jpg, bodies built in-browser from img/field/body*.png (recolor, skin match, headshot via /api/hs, injury glow). Classic SVG view kept behind a toggle.
- `src/feedback.js` — "Send feedback" (footer + account sheet) into the `feedback` table; owner Inbox tab on the admin page with a count on the header shield.
- `supabase/round5.sql` — `guests` table + `guest_checkin(device)` RPC: guests get a lasting number (Guest 1, 2, …) per device code; Activity tab shows it with visit counts.
- `supabase/round4.sql` — feedback table, members-only leagues, request cooldown, 500-char chat cap. `_headers` — security headers.
- `src/predict.js` + `functions/api/predict.js` — pre-game win chances (ESPN Matchup Predictor) on the next-game card, scoreboard, game sheet and pick'em.
- `src/flags.js` + `functions/api/penalties.js` — 🚩 Flags breakdown in the game sheet (every penalty per team from ESPN play-by-play, full names from rosters, accepted/declined/offsetting; cached 7 days once final) + Flags button on the home recap card.
- `src/watch.js` — Watch & listen sheet (official TV/streaming apps per network + radio), Watch button on game cards, live highlight clips on the game-day card.
- `src/chaingame.js` — "Kirko Chainz" QB throwing mini-game (home card after the field goal game): behind-the-QB camera, swipe to throw, shared sim step drives both play and the aim ring (open/contested/covered), 8 chain styles stack per completion, streak fire mode (×1.5/×2 bucks), three receivers (own route color, cornerback each) + safety, announcer: AI voice clips from `functions/api/announce.js` (Workers AI TTS, whitelist `announce_lines.js` regenerated by `scripts/cg_lines.py` on every build) with speechSynthesis fallback, crowd roar (mute saved in nh_cgmute), game-day mode (double bucks while CUR is live in LIVE.data; a real TD sets the stadium on fire), Huddle Bucks by distance also go into a bank (nh_cgwallet; members sync scores/<uid>.wallet) spent in the Shop (6 tabs via cgCats(): CG_SKINS balls, CG_TRAILS, CG_CELS celebrations, CG_STADS stadiums, CG_GLOVES, CG_EZ end zone art). Start menu (Play / Daily Challenge seeded by Chicago date, scores/<uid>.daily / Shop / Badges CG_ACH in wallet.ach, shown on member profiles), downs + TDs, pre-snap hot routes, share card (cgShare), best in localStorage + `scores/<uid>.chain` leaderboard.
- `src/admin.js` — owner-only admin page (Members / Chat / Leagues), opened from the account sheet or /#admin.
- `src/system.js` — admin System tab (default): topology map of sources → jobs → database → site → fans with live health, data freshness, scheduled jobs + run history, setup checklist, alert editor; also wakes the updater via `functions/api/kick.js` (GitHub workflow_dispatch, needs Pages secret GH_DISPATCH_TOKEN) when sys/status is >25 min old.
- `scripts/updater.py` + `.github/workflows/site-update.yml` — FREE auto-updater (replaces the Claude refresh/gameday/league/requests tasks): ESPN + vikings.com RSS + YouTube RSS → games, hub/meta, standings, players (+logs), depth, injuries, news, videos, pstats, fweeks/fstats, requests; summaries via the site's /api/summarize (Workers AI, admin-only); writes sys/status. Needs repo secret NH_BOT_PW. `--dry` previews. Claude tasks stand down when sys/status is fresh (tasks/common.md).
- `supabase/round6.sql` — security: write size caps, profile/request validation, league_guard trigger (commissioner-only role/member changes), 30 s lock cap, no email auto-admin, admins list admin-only, docs.updated_at touch trigger, sys/schema marker.
- `supabase/setup.sql` — database schema, access rules, RPCs (`doc_update` deep merge, `doc_acquire` lease). Re-runnable in the Supabase SQL Editor.
- `functions/api/boot.js` — all public bot-written collections in one 30 s edge-cached response; `src/shim.js` serves first loads and full refreshes from it (realtime changes still read the database directly). `src/chaingame_stub.js` — always-loaded Kirko Chainz card/badges/loader; build.py builds `src/chaingame.js` to `js/chaingame.js` (downloaded on Play/Shop). Stadium players build only when Depth is opened.
- `scripts/backup.py` + `.github/workflows/backup.yml` — nightly encrypted (NH_BOT_PW) database backup kept 30 days as an artifact; `--restore` puts docs back. `.github/dependabot.yml` — weekly Actions updates.
- `scripts/nh.py` — CLI for scheduled updates to read/write docs as the bot (`NH_BOT_PW` env var).

## Data
Collections (doc paths like `players/justin-jefferson`): hub/meta, news, players, games, standings, injuries, depth, videos, nfl, fantasy, tracked, pstats, league/standings, teams/<abbr>, fstats/wNN, fweeks/wNN (bot/admin write only) and leagues(+/chat), chat, gamechat, comments, reactions, predictions, votes, pickem, ranks, profiles/<uid> (bio, fav), scores/<uid>, requests, data/users/<uid>/settings (user-writable per rules in setup.sql).

## Trademark care
Public site: no team logos, no team names in the site name. Keep the footer disclaimer.

## Build notes
- `build.py` minifies inline JS/CSS when esbuild is available (`NH_ESBUILD=/path/to/esbuild` or `esbuild` on PATH); otherwise it writes a readable, unminified index.html (also fine to deploy). It also trims the built-in data snapshot and refreshes its meta from Supabase.
- Share previews: `functions/g/[id].js` (game links) and `functions/api/og.js` (1200x630 score image) use `lib/og/` (resvg wasm + Barlow Condensed fonts, OFL).
- Static pages: `privacy.html`, `terms.html` (#rules), `404.html`. Email templates to paste into Supabase: `supabase/emails/`.

## Moving to a custom domain
Update `SITE` in build.py and worker/alerts.js, the links in supabase/emails/*.html and privacy.html, then: Supabase → Authentication → URL Configuration (Site URL + redirect URLs), Google Cloud OAuth client (authorized JavaScript origins), re-paste the worker.
